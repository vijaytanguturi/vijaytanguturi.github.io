# Vijay Tanguturi — Engineering Leadership Portfolio

A lightweight, responsive personal portfolio built with plain HTML and CSS for GitHub Pages. No build step or paid hosting is required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named exactly `vijaytanguturi.github.io`.
2. Upload `index.html`, `styles.css`, and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for the deployment. Your site will be available at `https://vijaytanguturi.github.io`.

## Personalize before publishing

- Replace the LinkedIn and GitHub placeholder URLs in `index.html` with your actual profile URLs.
- Add a CV PDF only if you are comfortable making it publicly accessible. Link it from the hero section after uploading it.
- Review all claims and project descriptions. Add measurable results only when you can verify them and share them publicly.
- Do not include confidential client, employer, system, or performance data.
- Consider adding a professional email address or a contact form service if you want recruiters to contact you directly.

## Local preview

Open `index.html` in a browser. You can also use VS Code's Live Server extension.
